Context is everything the AI can "see"at any givin moment. 
    - Messages in your conversation
    - Any files you've referenced
    - System instructions
    - Its own responses

Context window = what it can hold in memory at once

Context engineering:
The practice of strategically feeding the AI the right information so it can actually help you.

Tokens
